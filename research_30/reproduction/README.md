# Instructions pour lancer la reproduction des expériences (Tâche G.1)

Ce répertoire contient les fichiers nécessaires pour reproduire les expériences de l'autre groupe (Tâche G.1). Les expériences évaluent la performance de l'algorithme implémenté dans `probabiliste.c`.


## Structure du répertoire
- `main.c`, `probabiliste.c`, `probabiliste.h` : Fichiers fournis par l'autre groupe.
- `src/` : Contient `board.c`, `player.c`, `card.c` (copiés depuis `research_30/experiments/src/`).
- `include/` : Contient `board.h`, `player.h`, `card.h` (copiés depuis `research_30/experiments/include/`).
- `experience.pdf` : Rapport d'expérience de l'autre groupe.
- `Makefile` : Fichier pour automatiser la compilation et l'exécution.

## Instructions pour lancer les expériences
1. Placez-vous dans le répertoire `research_30/reproduction/` :
   ```bash
   cd research_30/reproduction/
   ```
2. Compilez et exécutez les expériences avec la commande suivante :
   ```bash
   make run
   ```
