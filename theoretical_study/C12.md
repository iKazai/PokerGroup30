## 2. Calcul détaillé de P(C¹₂ ≥ C²₂)

### Cas par cas :

1. **J1 = (1,1)** [C¹₂=1]
   - Toutes les mains J2 ont C²₂ ≥ 2 ⇒ 0 cas favorables
   - Contribution : 0

2. **J1 = (1,2)** [C¹₂=2]
   - J2 = (1,2) [C²₂=2] : 1/45
   - J2 = (2,2) [C²₂=2] : 1/45
   - Total : 2/45

3. **J1 = (1,3)** [C¹₂=3]
   - Toutes les mains J2 ont C²₂ ≤ 3 ⇒ toutes favorables
   - (1,2):2/45 + (1,3):1/45 + (2,2):1/45 + (2,3):2/45 = 6/45

4. **J1 = (2,2)** [C¹₂=2]
   - J2 = (1,1) [C²₂=1] : 1/45
   - Total : 1/45

5. **J1 = (2,3)** [C¹₂=3]
   - J2 = (1,1) [C²₂=1] : 1/45
   - J2 = (1,2) [C²₂=2] : 2/45
   - J2 = (1,3) [C²₂=3] : 1/45
   - Total : 4/45

6. **J1 = (3,3)** [C¹₂=3]
   - J2 = (1,1) [C²₂=1] : 1/15 = 3/45
   - J2 = (1,2) [C²₂=2] : 2/45
   - J2 = (2,2) [C²₂=2] : 1/45
   - Total : 6/45

### Somme finale :
`0 + 2/45 + 6/45 + 1/45 + 4/45 + 6/45 = 19/45 ≈ 0.4222 (42.22%)`
